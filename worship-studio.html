Saving songs needs permission to write to the church website. One-time setup on this computer, about two minutes. After that nobody sees this again.

  1. Click this button (sign in as the church account if it asks):
    Open GitHub → New token ↗
  2. Name it anything, like worship studio. Expiration: No expiration.
  3. Repository access → Only select repositories → pick worship.
  4. Repository permissions → Add permissions → add Contents and Actions, and set both to Read and write.
  5. Generate token, copy it, paste it here.
Stored only in this browser. Never on the website.
